עולם האיטום - מיני סייט טמבור (גרסת עיצוב סטטית)

איך רואים:
1. לחלץ את ה-ZIP לתיקייה.
2. לפתוח את index.html בדפדפן (Chrome מומלץ). לא צריך שרת.
3. הניווט בין העמודים עובד בתוך התיקייה: עולם האיטום, איטום משטחים / גגות / חדרים רטובים / מישקים, 3 כתבות ו-3 עמודי מוצר (700, 790, סופר 8 HYBRID).

מה חשוב לדעת:
- עיצוב לפי האתר החי tambour.co.il ופיגמה (Tambour-Dev, Tambour - Website 2025). רוחב מסגרת מקסימלי 1488px, שוליים 100px מכל צד עד ~1690px.
- הסרטונים בתיקייה assets/video. בגרסה ה-lite הם חסרים (התמונות הממוזערות נשארות, ההפעלה לא תעבוד).
- תמונות ההירו של הקטגוריות הן מקבצים חדשים (1200px). תמונות הכתבות הן 350-500px - אין מקור גדול יותר באתר.
- אין עיצוב מובייל מלא - נבדק בעיקר בדסקטופ.
- קוד: css/styles.css (כל השינויים מצטברים בסופו), build.py מייצר את כל עמודי ה-HTML (לא חובה להריץ).

להעלאה ל-GitHub:
- התיקייה כוללת .gitignore שמוציא את קובצי הסרטונים (mp4/mov) כי הם גדולים מ-100MB, מגבלת GitHub.
- בתוך התיקייה: git init -b main  ->  git add .  ->  git commit -m "Tambour waterproofing mini-site"  ->  git remote add origin <כתובת-ה-repo>  ->  git push -u origin main
- הסרטונים (אם צריך) נשמרים בנפרד בתיקייה assets/video.
